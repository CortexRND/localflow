# Wispr Flow feature parity

This comparison uses the public Wispr Flow Help Center articles (help.wisprflow.ai)
and LocalFlow's merged code. “Have” means there is a
working local equivalent, not that the implementation is identical. Citations
in the notes identify the Wispr Help Center section used for each comparison.

| Wispr Flow feature | localflow status (Have / Partial / Not planned) | how to use it (shortcut / `lf` command / setup step) | notes |
| --- | --- | --- | --- |
| First-run setup and permissions | Partial | Run `lf setup` and follow the platform wizard. | No Wispr account or account-backed settings. Wispr source: Getting Started → “Set up Wispr Flow for your first dictation”; `localflow/setup_flow.py`. |
| Dictation into the active app | Have | Hold the configured push-to-talk shortcut. | Local transcription providers and injection are wired by `localflow/app.py`; `localflow/pushtotalk.py`. Wispr source: Getting Started → “Set up Wispr Flow for your first dictation”. |
| Hands-free/toggle dictation | Have | Configure a toggle shortcut in setup, then use it to start and stop. | `localflow/hotkey.py`, `localflow/pushtotalk.py`. Wispr source: Using Wispr Flow → “Use Flow hands-free”. |
| Keyboard shortcuts | Have | Set the push-to-talk, toggle, Command Mode, and paste/copy-last bindings in setup. | `localflow/config.py`, `localflow/setup_flow.py`, `localflow/hotkey.py`. Wispr source: Using Wispr Flow → “Customize keyboard and mouse shortcuts”. |
| Command Mode | Have | Hold the configured Command Mode shortcut, speak an instruction, then release. | Supports configured transform/command jobs; `localflow/pushtotalk.py`, `localflow/transform.py`. Wispr source: Using Wispr Flow → “How to use Command Mode”. |
| Transform selected text or dictate from an instruction | Partial | Use the configured transform or Command Mode shortcut. | LocalFlow has Polish, Prompt Engineer, and instruction jobs, but not Wispr's full transform catalog; `localflow/transform.py`. Wispr source: Using Wispr Flow → “Rewrite text with Transforms and custom prompts”. |
| Spoken punctuation and line breaks | Have | Say supported punctuation, “new line”, or “new paragraph” while dictating. | `localflow/formatting.py` handles spoken punctuation and breaks. Wispr source: Using Wispr Flow → “How do I use Smart Formatting & Backtrack”. |
| Backtrack / “scratch that” | Partial | Say “scratch that” in a dictation; use History to copy or retry a result. | LocalFlow has deterministic correction rules, not a context-aware rewrite of arbitrary self-corrections; `localflow/formatting.py`. Wispr source: Using Wispr Flow → “How do I use Smart Formatting & Backtrack”. |
| Smart formatting and list creation | Partial | Enable spoken formatting in setup; dictate punctuation and line-break commands. | Formatting is deterministic and narrower than Wispr's automatic list and grammar formatting; `localflow/formatting.py`. Wispr source: Using Wispr Flow → “How do I use Smart Formatting & Backtrack”. |
| Auto Cleanup levels | Have | Choose None, Light, or Medium in setup or the hub. | Cleanup is optional and uses configured LLM providers; `localflow/cleanup.py`, `localflow/setup_flow.py`, `localflow/hub_tk.py`. Wispr source: Using Wispr Flow → “Auto Cleanup: control how much Flow edits your dictation”. |
| Writing styles by app category | Have | Choose Formal, Casual, Very Casual, or Excited for Personal, Work, Email, and Other in the hub. | `localflow/context.py`, `localflow/formatting.py`, `localflow/hub_tk.py`. Wispr source: Using Wispr Flow → “How to setup Flow Styles”. |
| Personal dictionary | Have | Add words in `lf hub` → Dictionary, or use `lf dict add`. | Local dictionary is stored on this device; `localflow/dictionary.py`, `localflow/cli.py`. Wispr source: Using Wispr Flow → “Teach Flow your words with the dictionary”. |
| Bulk dictionary import | Have | `lf dict import <file.csv|file.json>`, or Import in `lf hub` → Dictionary. | CSV/JSON import (3 MB / 1000-entry cap) with added/skipped counts; snippets are not bulk-imported. `localflow/dictionary.py`, `localflow/cli.py`. Wispr source: Using Wispr Flow → “How Do I Bulk Import Dictionary Items and Snippets?”. |
| Snippets | Partial | Run `lf phrases` to open the phrase editor. | Hot phrases expand to configured text, but do not include Wispr's folders or sync; `localflow/hotphrases.py`, `localflow/phrases_window.py`. Wispr source: Using Wispr Flow → “Create and use snippets”. |
| Hot phrases | Have | Run `lf phrases` to add a trigger and expansion. | Expansion runs through `localflow/hotphrases.py`; `localflow/cli.py` exposes the command. Wispr source: Using Wispr Flow → “Create and use snippets”. |
| Context awareness | Partial | Set app-category overrides in setup/configuration. | LocalFlow categorizes the frontmost app; it does not use Wispr's website/context integrations; `localflow/context.py`, `localflow/app.py`. Wispr source: Using Wispr Flow → “Context Awareness”. |
| Multiple languages and language selection | Partial | Select a language supported by the configured STT model. | Model/language support depends on the provider; LocalFlow does not promise mixed-language behavior. `localflow/config.py`, `localflow/providers/`. Wispr source: Using Wispr Flow → “Use Flow with multiple languages”. |
| Wispr's full 100+ language catalog | Not planned | — | LocalFlow supports model-dependent language options, not Wispr's managed language catalog. Wispr source: Using Wispr Flow → “Use Flow with multiple languages”. |
| Microphone selection | Have | Pick an input device in the `lf setup` mic-test step (`[dictation] input_device`). | Lists local input devices; `localflow/setup_flow.py`, `localflow/audio.py`. Wispr source: Transcription Accuracy & Voice Quality → “Connect and choose a microphone for Flow”. |
| IDE-specific dictation | Partial | Use the standard push-to-talk shortcut in an IDE. | Dictation works in the focused app; no dedicated IDE plugin is included. Wispr source: Using Wispr Flow → “Use Flow with Cursor, VS Code, and other IDEs”. |
| Dictation history | Have | Open `lf hub` → History or run `lf history`. | Local SQLite history, optional audio retention, search, and paging; `localflow/history.py`, `localflow/hub_tk.py`. Wispr source: Using Wispr Flow → “Delete transcripts and history in Wispr Flow”. |
| Delete and clear history | Have | Delete a row or clear History in `lf hub`. | Operates on local history; `localflow/history.py`, `localflow/hub_tk.py`. Wispr source: Using Wispr Flow → “Delete transcripts and history in Wispr Flow”. |
| Retry a failed transcription | Have | Choose Retry on an eligible audio-backed History row. | Retries the saved clip through the normal transcription pipeline; `localflow/app.py`, `localflow/history.py`. Wispr source: Troubleshooting → “Retry and recover a failed transcription”. |
| Usage and dictation statistics | Have | Open `lf hub` → Home or run `lf stats`. | Local counts and streaks; `localflow/history.py`, `localflow/cli.py`, `localflow/hub_tk.py`. Wispr source: Using Wispr Flow → “Your Usage tab: Track your dictation stats in Wispr Flow”. |
| Long dictation sessions | Have | Dictate up to `[dictation] max_recording_seconds` (default 1200 = 20 min; 0 = no limit). | A warning cue plays 60 s before the limit; at the limit the clip is transcribed, not discarded. `localflow/pushtotalk.py`, `localflow/config.py`. Wispr source: Using Wispr Flow → “Longer dictation sessions — now up to 20 minutes”. |
| Audio-file upload for transcription | Not planned | — | LocalFlow records from the microphone; it has no Wispr-style upload service. Wispr source: Using Wispr Flow → “Can I upload audio files to Wispr Flow for transcription?”. |
| Cross-device transcript/audio sync | Not planned | — | History and audio are local to one installation; there is no account-backed synchronization. `localflow/history.py`. Wispr source: Privacy, Security & Data → “Manage data sharing, cloud storage and local history”. |
| Team dictionaries and shared snippets | Not planned | — | Dictionary and phrases are local; there is no team account or shared library. `localflow/dictionary.py`, `localflow/hotphrases.py`. Wispr source: Privacy, Security & Data → “Restrict org-wide snippet and dictionary sharing” (listed in `wispr-llms.txt`). |
| Mobile keyboard, iOS/Android app, and mobile bubble | Not planned | — | LocalFlow is a desktop app and does not ship a mobile keyboard or mobile client. Wispr source: Getting Started → “Set up Wispr Flow for your first dictation”; Using Wispr Flow → “Navigating the Wispr Flow App: Desktop, iOS, and Android”. |
| Wispr-hosted cloud speech models/catalog | Not planned | — | LocalFlow's STT path uses locally installed providers/models. Optional remote LLM cleanup is configurable, but is not a Wispr-hosted STT catalog; `localflow/providers/`, `localflow/cleanup.py`. Wispr source: Troubleshooting → “Fix Flow startup and No Model Available errors”. |
| Cloud storage and data sharing | Not planned | — | LocalFlow keeps its history and preferences local; it has no Wispr account cloud-storage feature. Wispr source: Privacy, Security & Data → “Manage data sharing, cloud storage and local history”. |
| Dedicated whispering mode | Not planned | — | LocalFlow has no whisper-specific mode. Wispr's microphone guide gives quiet-speech setup advice rather than documenting a distinct mode. Wispr source: Transcription Accuracy & Voice Quality → “Using Wispr Flow Discreetly: Microphone Guide”. |
| Scratchpad / synchronized notes | Not planned | — | LocalFlow does not provide a cross-device notes space. Wispr source: Using Wispr Flow → “Use and organize notes in Scratchpad”. |
| Voice Profile / learned voice preferences | Not planned | — | No user voice-profile training or account sync is implemented. Wispr source: Transcription Accuracy & Voice Quality → “Voice Profile updates: when the 'Update your Voice Profile' notification appears” (listed in `wispr-llms.txt`). |
| Custom keyboard/mouse controls for the Flow Bar | Not planned | — | LocalFlow has desktop shortcuts, but no floating Flow Bar to move or dock. Wispr source: Using Wispr Flow → “Move and Dock the Flow Bar on Desktop”. |
| MCP client integration | Not planned | — | LocalFlow does not expose Wispr's MCP integration. Wispr source: Using Wispr Flow → “Connect Claude, ChatGPT or another MCP client to Wispr Flow”. |
