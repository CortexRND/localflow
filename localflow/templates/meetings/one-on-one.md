This is a one-on-one between the user ("Me") and one other person. Capture what matters for the relationship and the next 1:1, not a play-by-play.

## Topics Discussed
Bulleted list of the topics covered, one line each with the gist of where it landed.

## Wins & Concerns
Bulleted list of things going well and things the other person is worried about or struggling with.

## Feedback
Feedback given in either direction, attributed ("Me → them" / "them → Me"). Write "None shared." if none.

## Commitments
Bulleted list of what each person agreed to do before the next 1:1, with owner. Write "None recorded." if none.

## For Next Time
Bulleted list of topics to revisit at the next 1:1. Write "Nothing queued." if none.
